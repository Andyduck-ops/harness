# 动态探索策略 — 知识地图空白识别与方向演化

## 种子方向 → 动态演化

用户给出 3-5 个大方向（seeds），nightshift 从这里开始，
但不限于这些方向——探索过程中会自然发现新的有价值子领域。

## 空白识别信号

| 信号 | 含义 | Cartographer 行动 |
|------|------|-------------------|
| topic 下 < 3 patterns | 薄弱区域 | 优先派 Scout 探索 |
| 最近 10 轮无新 pattern | 停滞区域 | 换搜索角度 / 换语言 |
| 多个 `[CONFLICT]` | 争议区域 | 派 Scout 找更多证据 |
| 用户 seed 未覆盖 | 全新区域 | 初始广度搜索 |
| 平均 confidence < 0.6 | 低置信区域 | 派 Scout 找验证证据 |
| Serendipity 发现 | 意外区域 | 评估是否开辟新 topic |

## 方向演化规则

### 扩展
发现新的有价值子领域 → 添加到 active_directions

触发条件：Scout 报告 `[SERENDIPITY]` 且 Analyst 确认 confidence ≥ 0.6

### 收缩
某方向连续 5 轮无新 findings → 移入 exhausted_directions

不删除——后续可能因为新信源重新激活。

### 分裂
一个方向太宽泛（单轮产出 > 5 个不同元问题）→ 拆分为子方向

例："AI agent 工作流" → "上下文管理"、"质量门控"、"并行执行"

### 合并
两个方向实质是同一问题的不同表述 → 合并为一个方向

例："知识复利" + "经验积累" → "知识进化"

### Serendipity 注入
Scout 的意外发现 → 可能催生全新方向

这是动态探索的核心价值——预设计划永远无法覆盖的发现。

## 探索深度控制

每个方向有三级深度：

| 深度 | 搜索策略 | 产出预期 |
|------|---------|----------|
| L1 广度 | 3-5 个泛搜索词 | 初步了解，识别关键概念 |
| L2 聚焦 | 从 L1 结果提取具体关键词 | 核心 patterns |
| L3 精深 | 追踪具体论文/项目/人物 | 实现变体和边界条件 |

新方向从 L1 开始。Cartographer 根据 findings 质量决定是否深入。

## 搜索词生成策略

Cartographer 为 Scout 生成搜索词时：

1. **核心概念词** — 直接搜索方向关键词
2. **对立面** — 搜索反面观点（"why X fails", "alternatives to X"）
3. **实践报告** — 搜索真实使用经验（"X in production", "X postmortem"）
4. **学术/源头** — 搜索原始论文或创始人文章
5. **中文生态** — 中文社区可能有独特视角
