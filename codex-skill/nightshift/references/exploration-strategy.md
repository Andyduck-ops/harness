# 动态探索策略 — 知识地图空白识别与方向演化

## 种子方向 → 动态演化

用户给出 3-5 个大方向（seeds），nightshift 从这里开始，
但不限于这些方向——探索过程中会自然发现新的有价值子领域。

## 硬约束

**active_directions ≤ 15。** 这是不可突破的上限。

第一轮运行的教训：5 个种子方向膨胀到 93 个 active_directions，
导致治理递归（同一主题反复 split 出微小变体）。

## 空白识别信号

| 信号 | 含义 | Cartographer 行动 |
|------|------|-------------------|
| topic 下 < 3 patterns | 薄弱区域 | 优先派 Scout 探索 |
| 最近 10 轮无新 pattern | 停滞区域 | 换搜索角度 / 换语言 |
| 多个 `[CONFLICT]` 标记 | 争议区域 | 派 Scout 找更多证据 |
| 用户大方向未覆盖 | 全新区域 | 初始广度搜索 |
| Serendipity 发现 | 意外区域 | 评估是否开辟新 topic（需空槽） |

## 方向演化规则（按优先级排序）

**先释放空间，再占用空间。**

### 1. 收缩（优先执行）
某方向连续 5 轮无新 findings → 移入 dormant_directions

不删除——后续可能因为新信源重新激活。

dormant 超过 10 cycles → archive。

### 2. 合并（优先执行）
两个方向实质是同一问题的不同表述 → 合并为一个方向

判断方法（功能性，非量化）：
- 两个方向的 patterns 能解决的具体场景有重叠吗？
- 如果只保留一个方向，另一个的 patterns 会无家可归吗？
- 重叠多 → 合并；各自独立 → 保留

### 3. 扩展（需空槽）
触发条件：Scout 报告 `[SERENDIPITY]` 且 Analyst 确认有价值

无空槽时：必须先收缩或合并释放一个槽位

### 4. 分裂（需空槽 + 极端情况）
一个方向单轮产出 > 5 个不同元问题 → 拆分为子方向

**分裂是最后手段。** 优先考虑：这些"不同元问题"是否本质上是同一个问题的不同切面？

### 5. Serendipity 注入
Scout 的意外发现 → 走扩展流程，需空槽

## 探索深度控制

每个方向有三级深度：

| 深度 | 搜索策略 | 产出预期 |
|------|---------|----------|
| L1 广度 | 3-5 个泛搜索词 | 初步了解，识别关键概念 |
| L2 聚焦 | 从 L1 结果提取具体关键词 | 核心 patterns |
| L3 精深 | 追踪具体论文/项目/人物 | 实现变体和边界条件 |

新方向从 L1 开始。Cartographer 根据 findings 质量决定是否深入。

**饱和信号**：当一个方向在 L3 连续 3 轮只产出已有 pattern 的变体 → 该方向已饱和，收缩。

## 搜索词生成策略

Cartographer 为 Scout 生成搜索词时：

1. **核心概念词** — 直接搜索方向关键词
2. **对立面** — 搜索反面观点（"why X fails", "alternatives to X"）
3. **实践报告** — 搜索真实使用经验（"X in production", "X postmortem"）
4. **学术/源头** — 搜索原始论文或创始人文章
5. **中文生态** — 中文社区可能有独特视角
