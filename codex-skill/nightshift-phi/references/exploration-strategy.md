# 动态探索策略 — 哲学与方法论知识地图

## 种子方向

用户给出 3-7 个大方向（seeds），nightshift-phi 从这里开始，
但不限于这些方向——思想之间的关联会自然暴露新的子领域。

## 推荐种子方向

| 方向 | 核心问题 | 关键人物/著作 |
|------|---------|-------------|
| 系统论与控制论 | 反馈、涌现、非线性、杠杆点 | Meadows, Ashby, Wiener, Senge |
| 认识论与知识验证 | 怎么判断"知道了"、证伪、贝叶斯 | Popper, Kuhn, Taleb, Jaynes |
| 决策论 | OODA, 有限理性, 反脆弱 | Boyd, Simon, Kahneman, Taleb |
| 复杂性科学 | 涌现、自组织、临界、幂律 | Santa Fe Institute, Holland, Wolfram |
| 精益与约束理论 | 消除浪费、瓶颈、流 | Ohno, Goldratt, Deming |
| 演化与适应 | 变异-选择-遗传、红皇后、适应性景观 | Darwin, Kauffman, Dawkins |
| 中国哲学方法论 | 实践论、矛盾论、知行合一 | 毛泽东, 王阳明, 孙子 |

## 硬约束

**active_directions ≤ 15。** 这是不可突破的上限。

## 空白识别信号

| 信号 | 含义 | Cartographer 行动 |
|------|------|-------------------|
| topic 下 < 3 patterns | 薄弱区域 | 优先派 Scout 探索 |
| 最近 10 轮无新 pattern | 停滞/饱和 | 换搜索角度 / 换语言 |
| 多个 `[CONFLICT]` 标记 | 学派争议 | 派 Scout 找更多证据和适用条件 |
| 用户大方向未覆盖 | 全新区域 | 初始广度搜索 |
| Serendipity 发现 | 意外关联 | 评估是否开辟新 topic（需空槽） |

## 方向演化规则（按优先级排序）

**先释放空间，再占用空间。**

### 1. 收缩（优先执行）
某方向连续 5 轮无新 findings → 移入 dormant_directions

dormant 超过 10 cycles → archive。

### 2. 合并（优先执行）
两个方向实质是同一元问题的不同表述 → 合并为一个方向

判断方法（功能性，非量化）：
- 两个方向的 patterns 能指导的具体决策有重叠吗？
- 如果只保留一个方向，另一个的 patterns 会无家可归吗？
- 重叠多 → 合并；各自独立 → 保留

### 3. 扩展（需空槽）
触发条件：Scout 报告 `[SERENDIPITY]` 且 Analyst 确认有跨领域迁移价值

无空槽时：必须先收缩或合并释放一个槽位

### 4. 分裂（需空槽 + 极端情况）
一个方向单轮产出 > 5 个不同元问题 → 拆分为子方向

**分裂是最后手段。** 优先考虑：这些"不同元问题"是否本质上是同一个问题的不同切面？

### 5. Serendipity 注入
Scout 的意外发现 → 走扩展流程，需空槽

## 探索深度控制

每个方向有三级深度：

| 深度 | 搜索策略 | 产出预期 |
|------|---------|----------|
| L1 广度 | 核心概念 + 关键人物 | 初步了解，识别主要学派 |
| L2 聚焦 | 追踪具体理论和争议 | 核心 patterns + 学派对比 |
| L3 精深 | 原始著作 + 历史案例 + 反例 | 适用边界和失败条件 |

新方向从 L1 开始。Cartographer 根据 findings 质量决定是否深入。

**饱和信号**：当一个方向在 L3 连续 3 轮只产出已有 pattern 的变体 → 该方向已饱和，收缩。

## 搜索词生成策略

Cartographer 为 Scout 生成搜索词时：

1. **原始著作** — 搜索原始作者和原始论述
2. **对立面** — 搜索批评和反驳（"criticism of X", "limits of X"）
3. **实践验证** — 搜索实际应用案例（"X in practice", "applying X to"）
4. **跨领域迁移** — 搜索该方法论在其他领域的应用
5. **中文视角** — 中文学术圈可能有独特解读
6. **历史脉络** — 搜索思想演化链（"X influenced by", "history of X"）
