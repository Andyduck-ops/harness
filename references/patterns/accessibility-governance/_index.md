# accessibility-governance

- [theme-contrast-readability-budget-gate](./theme-contrast-readability-budget-gate.md) — 用文本/非文本对比预算与多主题回放，把可读性回退变成可阻断晋级门禁
- [theme-contrast-regression-slope-gate](./theme-contrast-regression-slope-gate.md) — 在绝对阈值之外引入对比回退斜率预算，防止“达标但断崖式退化”进入晋级链路
- [color-vision-simulation-replay-gate](./color-vision-simulation-replay-gate.md) — 把色觉仿真回放与文本/非文本对比预算并列成 required check，阻断“标准达标但特定人群不可用”的隐性回退
