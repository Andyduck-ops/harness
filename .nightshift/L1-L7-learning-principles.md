# L1-L7 学习原则（Nightshift）

L1. 目标导向：学习目标是“决策增益”，不是“条目增量”。
L2. 同构收敛：同一元问题只允许一个 canonical pattern，其他并入 variants。
L3. 证据优先：优先官方/一手资料；无证据链仅可进入候选，不可入主索引。
L4. 同化判定：默认同化，但判定标准是“同化后检索信噪比不下降”；若信噪比会下降则新建。
L5. 预算约束：per-topic <= 5 patterns；方向总数 <= 15。
L6. 周期收敛：每 5 cycles 必须执行压缩合并（merge > split）。
L7. 可检索性：每轮写完必须做检索测试；不把“元问题是否相同”做伪量化硬阈值。
