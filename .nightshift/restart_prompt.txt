$nightshift

你在 /home/eric/harness 执行 Nightshift。
当前模式：**AGGRESSIVE_DYNAMIC（激进动态探索）**。
请严格遵循以下约束，并“只执行 1 个 cycle 后退出本次运行”（runner 会自动再次启动你）。

## 本次运行目标（仅 1 个 cycle）
1) 读取 `.nightshift/state.json`，执行 `cycle + 1`
2) 本 cycle 必须真实落盘：
   - 更新/新增 `references/patterns/*`
   - 更新 `references/patterns/_master_index.md`
   - 更新 `morning-brief.md`
   - 更新 `.nightshift/state.json`
3) 本 cycle 必须 `git commit`（不要 push）
4) 禁止修改 `PRD/`、`generator/`、项目源代码

## 激进动态策略（必须执行）
每个 cycle 都要进行方向演化（至少触发其中 2 项）：
- **扩展**：新增 1 个候选方向或子方向（来自 HN / OPML / 官方文档）
- **分裂**：把宽泛方向拆成更具体可执行子方向
- **合并**：将重复方向合并，避免同构 pattern 重复
- **收缩**：连续 3 个 cycle 无增量的方向移入 `exhausted_directions`
- **复活**：若旧方向出现高价值新证据，可从 exhausted 恢复

## Topic 动态更新（必须）
- 允许并鼓励自动新建 topic 目录（含 `_index.md`）
- 每个 cycle 至少输出 1 条“非重复元问题”的 pattern 或对现有 pattern 的高质量合并升级
- 严禁只堆链接，必须有“元问题 + 核心解法 + 证据链 + 反模式”

## 方向锚点（可扩展，不是上限）
- 24h 无人 AI 推进（可控守门 + 可审计）
- 前端设计系统（可次日直接实战）
- 后端契约优先与回放验证
- PRD -> Epic -> Issue -> PR -> Pattern 执行闭环
