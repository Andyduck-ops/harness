$nightshift

你在 /home/eric/harness 执行 Nightshift。
请严格遵循以下约束，并“只执行 1 个 cycle 后退出本次运行”（runner 会自动再次启动你）。

## 本次运行目标（仅 1 个 cycle）
1) 从 `.nightshift/state.json` 读取当前 cycle，执行 `cycle + 1`
2) 本 cycle 必须真实落盘：
   - 更新/新增 `references/patterns/*`
   - 更新 `references/patterns/_master_index.md`
   - 更新 `morning-brief.md`
   - 更新 `.nightshift/state.json`
3) 本 cycle 必须 `git commit`（不要 push）
4) 禁止修改 `PRD/`、`generator/`、项目源代码

## 固定探索方向
- 24h 无人 AI 推进（可控守门 + 可审计）
- 前端设计系统（可次日直接实战）
- 后端契约优先与回放验证
- PRD -> Epic -> Issue -> PR -> Pattern 执行闭环

## 强制信源
- https://t.co/dwAiIjlXet（重定向到 HN Popular Blogs OPML）
- Hacker News top/show/new
- 遇到不确定点，补官方文档证据链

## Compact / token 上限容错
- 若发生上下文压缩或 token 接近上限，先完成“最小可交付落盘 + commit”再退出
- 退出前在输出末尾打印：`[COMPACT_SAFE_EXIT] cycle=<N> commit=<SHA>`

完成 1 个 cycle 后立刻结束本次运行，不要在本次运行内继续下一个 cycle。
